Python-based automation tool that translates natural language instructions into executable Windows Batch (.bat) commands using the Kimi K2 filmmakerdiaries (Moonshot AI) model. This project eliminates the need to remember complex CMD syntax for file management, system diagnostics, and bulk organization tasks and more.

Tech Stack: Python, OpenAI SDK (Hugging Face Router)
